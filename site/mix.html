17.1  free vs available

TL;DR
  - free: memory nobody is using at all, not even as cache.
  - available: what your apps can still get without swapping.
  - Look at available, not free: the available column of
    the Mem: line in free -h.

      free -h

On your machine
  RAM       10.5 GiB available of 15.5 GiB (68%)
            · 1.1 GiB completely free
  Cache     7.5 GiB in buff/cache, 604.0 MiB of it shared
  Swap      256.0 MiB used of 8.0 GiB · swappiness 60

Pitfalls
  - "free" near zero is normal: Linux fills spare RAM
    with page cache.
  - A little swap in use is not a problem by itself.
    What hurts is constant swapping: watch the si and so
    columns of vmstat 1.

It looks. It never touches.

atfq shows commands and reads state. It never runs your commands and never changes the system, so you can point it at a production box.

Install

Linux only, glibc 2.35 or later for the prebuilt binaries. Each release lists SHA-256 sums.

Prebuilt

x86-64 shown; use aarch64 on ARM.

curl -LO https://github.com/moha-bekh/atfq/releases/latest/download/atfq-x86_64-linux.tar.gz
tar xzf atfq-x86_64-linux.tar.gz
install -m 755 atfq-x86_64-linux/atfq ~/.local/bin/

From source

With a Rust toolchain.

git clone https://github.com/moha-bekh/atfq
cd atfq
cargo install --path .
